# MVP Demo Script

This file defines the demo flow Radar must support before first pilot sales.

## Scenario

A B2B SaaS company wants to verify that customer-facing promises remain correct across pricing, refund policy, onboarding, billing, and support escalation.

## Demo flow

1. Open Command Center and show daily summary.
2. Add a pricing page and refund policy source.
3. Generate suggested assertions.
4. Approve Pricing & Plan Accuracy and Refund & Cancellation assertions.
5. Generate test cases.
6. Run Knowledge Runner.
7. Show a failed refund answer.
8. Open Finding detail and show expected vs actual evidence.
9. Show recommended fix.
10. Rerun after simulated fix.
11. Return to Command Center and show improved state.

## Demo output language

Use simple copy such as: `281 checks ran, 4 exceptions, 2 recommended fixes.`
